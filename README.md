# 🍕 Pizza Sales Dashboard (Power BI)

This repository contains a Power BI Dashboard for analyzing Pizza Sales Data. The dashboard provides insights into total revenue, customer trends, popular pizza categories, and order distribution to support data-driven decision-making for a pizza business.# pizza_sales_analysis-MySql-Bi-

🚀 Project Overview
 - The aim of this BI project is to:
 - Track Total Revenue, Total Orders, and Average Order Value.
 - Analyze pizza category and size performance.
 - Identify best-selling and least-selling pizzas.
 - Monitor sales trends by time (daily, monthly, and hourly).
 - Support business strategy and marketing decisions.

📌 Key Features
📊 KPI Cards: Revenue, Total Orders, Average Order Value.
🍕 Top & Bottom 5 Pizzas: Best and worst sellers by revenue.
⏰ Sales Trends: Hourly, Daily, Monthly revenue analysis.
🥤 Category & Size Analysis: Compare performance of pizza types (Classic, Supreme, etc.) and sizes (S, M, L, XL).
📍 Interactive Filters: Drill-down by time, category, and size.

🛠️ Tools & Technologies Used
 - Power BI Desktop – Dashboard & visualization.
 - Power Query – Data cleaning & transformation.
 - DAX (Data Analysis Expressions) – Custom measures & KPIs.
 - CSV/Excel Dataset – Pizza sales transactional data.
